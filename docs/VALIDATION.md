## Environment limitations

- Four native video integration tests were explicitly skipped after an independent VideoToolbox encoder probe returned status `-12908`. A direct system-encoder control test also could not create HEVC in the restricted process. These skips are not evidence that the encoding pipeline passed.
- Two native audio integration tests were explicitly skipped because Core Audio's independent encoder enumeration exposed neither AAC nor ALAC in the restricted command-line process. The system `afconvert` utility independently reported neither codec there. The later LaunchServices diagnostic app successfully exported and independently verified ALAC/AAC. HEVC also worked in that host. The restriction is specific to the CLI context; it does not prove the codecs are missing from macOS.
- GUI automation later stopped responding and screen capture reported `SCStreamErrorDomain -3811`. A complete open/compress/save GUI flow, including the updated asynchronous panels, could not be verified in this session.
- During the later design review, screenshots and native navigation worked again, but the system file chooser kept its Add Files button disabled after navigating to a known synthetic text file. Explicit file/folder selection and content-type configuration did not resolve this during automation. The cause is unconfirmed. The new progress/result/save presentation has compiled but has not been verified end to end with a selected file in the GUI. Confirm the chooser behavior manually and investigate it before release; do not treat this as a successful GUI compression test.
- The current implementation replaces the custom open-panel configuration with SwiftUI's system file importer and separate file/folder actions. The same synthetic text file appeared in the system chooser, but Open remained disabled during automation. This confirms the earlier failure was not resolved by this change. File-table population, progress, result, and save presentation still require end-to-end manual validation. No successful GUI compression/export is claimed.
